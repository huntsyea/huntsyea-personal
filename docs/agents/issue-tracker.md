# Issue tracker

This Sylph fork uses [GitHub Issues](https://github.com/huntsyea/sylph/issues) as its project issue tracker because `huntsyea/sylph` is the owned `origin` remote.

Engineering skills should publish durable specifications, plans, and implementation work to `huntsyea/sylph` GitHub Issues. The source project, `raphaelsalaja/sylph`, is the read-only `upstream` and must not receive fork-specific planning artifacts. Do not create parallel local Markdown tickets unless GitHub is unavailable or a future repository convention explicitly replaces this rule.
