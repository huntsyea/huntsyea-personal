# Issue tracker

This repository uses [GitHub Issues](https://github.com/huntsyea/huntsyea-personal/issues) as its project issue tracker because `huntsyea/huntsyea-personal` is the owned `origin` remote.

Engineering skills should publish durable specifications, plans, and implementation work to `huntsyea/huntsyea-personal` GitHub Issues. The source project, `raphaelsalaja/sylph`, is the read-only `upstream` and must not receive repository-specific planning artifacts. Do not create parallel local Markdown tickets unless GitHub is unavailable or a future repository convention explicitly replaces this rule.
