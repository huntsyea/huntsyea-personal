# Triage labels

Use the following one-to-one GitHub label vocabulary:

| Workflow state                                       | GitHub label      |
| ---------------------------------------------------- | ----------------- |
| Work has not been classified                         | `needs-triage`    |
| Work requires missing information                    | `needs-info`      |
| Work is specified and can be implemented by an agent | `ready-for-agent` |
| Work requires a human-only action or decision        | `ready-for-human` |
| Work will not be implemented                         | `wontfix`         |

Preserve these meanings when adding topical labels such as `bug`, `enhancement`, or `documentation`. A topical label does not replace a workflow-state label.
